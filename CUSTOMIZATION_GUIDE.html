1️⃣ Change Dress Images & Details

Location: js/products.js

c:\Users\wadan khan\Desktop\aljannat\js\products.js

This file contains all your dress product information. Every dress has:

  • name - Dress name (e.g., "Aurora Silk Dress") ← CHANGE THIS
  • price - Original price ← CHANGE THIS
  • salePrice - Discounted price ← CHANGE THIS
  • image - Main product image URL ← CHANGE THIS
  • hoverImage - Image that shows on hover ← CHANGE THIS
  • description - Product description ← CHANGE THIS
  • colors - Available colors ← CHANGE THIS
  • sizes - Available sizes (XS, S, M, L, XL, XXL) ← CHANGE THIS
  • rating - Star rating (e.g., 4.9) ← CHANGE THIS
  • stock - Stock status (In Stock, Low Stock, Pre-Order) ← CHANGE THIS
  • badge - Label (New, Sale, Limited Edition, Bridal, Luxury) ← CHANGE THIS

Example: Change Product #1

const products = [ { id: 1, name: 'Aurora Silk Dress', // ← CHANGE DRESS NAME category: 'party', collection: 'luxury', price: 620, // ← CHANGE PRICE salePrice: 540, // ← CHANGE SALE PRICE rating: 4.9, colors: ['Gold', 'Black'], // ← CHANGE COLORS sizes: ['XS', 'S', 'M', 'L'], // ← CHANGE SIZES stock: 'In Stock', // ← CHANGE STOCK STATUS image: 'https://images.unsplash.com/...', // ← CHANGE MAIN IMAGE hoverImage: 'https://images.unsplash.com/...', // ← CHANGE HOVER IMAGE badge: 'Limited Edition', // ← CHANGE BADGE description: 'A sculpted silk gown...' // ← CHANGE DESCRIPTION } ];

How to Update a Single Dress

  1. Open js/products.js
  2. Find the dress you want to change (look for id: 1, id: 2, etc.)
  3. Change the properties you want (name, price, image URL, description)
  4. Save the file
  5. Refresh your browser to see the changes

How to Add a New Dress

const products = [ // ... existing dresses ... { id: 7, // New unique ID (increment from last) name: 'Your Dress Name', category: 'midi', collection: 'luxury', price: 500, salePrice: 450, rating: 5.0, colors: ['Red', 'Blue'], sizes: ['S', 'M', 'L'], stock: 'In Stock', image: 'assets/images/products/dress7.jpg', hoverImage: 'assets/images/products/dress7-hover.jpg', badge: 'New', description: 'Your dress description here' } ];
💡 Tip: When adding a new dress, make sure the id is unique and higher than existing IDs. This prevents conflicts.

Step-by-Step: Update Footer

  1. Open each HTML file (index.html, collections.html, etc.)
  2. Find the <footer> section at the bottom
  3. Replace the email: hello@aljannat.com → your email
  4. Replace the phone: +966 55 123 4567 → your phone
  5. Replace the location: Riyadh, Saudi Arabia → your city
  6. Update company description if needed
  7. Save and refresh browser
⚠️ Important: Update the footer in ALL 8 HTML files, not just index.html. Otherwise, old info will show on other pages.

5️⃣ Where to Upload Images

Since this is a frontend-only site with no backend, you have 3 options for storing dress images:

Option A: Use External URLs (Easiest) ⭐ RECOMMENDED

Best for: Quick setup, no file management

  • Unsplash - Free high-quality images - https://unsplash.com
  • Pexels - Free stock photos - https://pexels.com
  • Pixabay - Free images - https://pixabay.com
  • Shopify - Your hosted images

How to use: Copy the image URL and paste it into js/products.js

image: 'https://images.unsplash.com/photo-1234567890?auto=format&fit=crop&w=900&q=80',

Option B: Store Images Locally

Best for: Full control, permanent storage

  1. Save your dress images to: assets/images/products/
  2. Name them clearly: dress-name-1.jpg, dress-name-2.jpg
  3. Update js/products.js:
    image: 'assets/images/products/aurora-dress.jpg', hoverImage: 'assets/images/products/aurora-dress-hover.jpg',
  4. Save and refresh browser

Folder Structure for Local Images

aljannat/ ├── assets/ │ └── images/ │ └── products/ │ ├── dress1.jpg ← Your dress images go here │ ├── dress1-hover.jpg │ ├── dress2.jpg │ ├── dress2-hover.jpg │ └── ... more dresses ...

Option C: Use a Cloud Service (Advanced)

Best for: Large-scale production, flexible storage

  • AWS S3 - Amazon storage
  • Cloudinary - Image hosting & optimization
  • Firebase Storage - Google cloud storage
  • Imgbb - Free image hosting - https://imgbb.com

Upload images to cloud service, get URL, paste in js/products.js

Option Cost Speed Difficulty
External URLs Free Fast Easy
Local Files Free Fast Easy
Cloud Service Free/Paid Very Fast Medium
